# Stock Market Analysis

## Project Overview

This project analyzes historical stock market data using Python, SQL, Pandas, and Matplotlib.

The project performs data processing, calculates important stock market metrics, stores the data in MySQL, and generates visualizations to understand stock performance.

## Technologies Used

- Python
- Pandas
- MySQL
- SQL
- Matplotlib
- Git & GitHub

## Key Analysis

The project analyzes:

- Average Closing Price
- Highest Closing Price
- Lowest Closing Price
- Average Daily Return
- Stock Volatility
- Up and Down Trading Days
- Total Trading Volume

## Project Workflow

Stock Data  
↓  
Data Cleaning & ETL  
↓  
MySQL Database  
↓  
SQL Analysis  
↓  
Python Analysis  
↓  
Visualizations

## Output

The project generates stock summaries and graphical visualizations to compare the performance of different stocks.
